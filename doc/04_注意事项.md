# 04 · 注意事项（踩坑清单）

## 硬件 / 接线

1. **INMP441 只能 3.3V**，接 5V 会损坏。由 Pico 的 **3V3（Pin 36）** 供电。
2. **别把 3V3 和 3V3_EN 搞混**：Pin 36 = `3V3`（电源输出，可供电）；**Pin 37 = `3V3_EN`**（稳压器使能输入，**不是电源**）。
3. **VDD 退耦**：INMP441 的 VDD 与 GND 之间就近并联 **0.1 µF** 陶瓷电容；否则容易出现噪声/杂音。
4. **L/R 接地** = 选择左声道（单麦必须接地，否则声道不确定）。
5. **CHIPEN** 需为高电平才工作；多数模块内部已上拉，可不接，悬空会掉电。
6. **SCK/WS/SD 走线尽量短**，远离电源与射频噪声。

## I²S 引脚硬约束（最容易接反）

PIO 的 `i2s_in_slave` 按 `din / din+1 / din+2` 读引脚；`i2s_out_master` 在 `base / base+1` 产生 BCK/LRCLK。两者共用时钟脚，因此必须满足：

```
clock_pin_base == din_pin + 1
```

即三个 GPIO **连续**，且顺序固定为：

```
SD = din_pin（编号最小）  →  SCK = din+1  →  WS = din+2
```

- 主线（v0.3）：`SD=GP7, SCK=GP8, WS=GP9`（实际硬件接线，写死，不再支持 GP18/19/20）

⚠️ 若把 SCK 接到最小编号、SD 接到最大编号（常见笔误），**信号全部错位、完全采不到声音**。

对应代码：`src/rec_buffer.c` 里 `my_i2s_config = { fs, sck_mult, bit_depth, sck_pin, dout_pin, din_pin, clock_pin_base, sck_enable }`。
改引脚只需改 `din_pin` 与 `clock_pin_base` 两个字段（保持 `clock_pin_base = din_pin + 1`）。

## 工具链（容易卡住）

7. **pioasm 必须 2.1.1**：SDK 2.1.1 调用 `pioasm -v <版本>` 生成 `.pio.h`，1.x 版 pioasm 不认 `-v`，会报 `error: unknown option -v`。
8. **picotool 必须 ≥ 2.1.1**：SDK 用 `find_package(picotool 2.1.1 CONFIG)`，版本不足会 FATAL_ERROR。picotool 官方 release **只有源码、无 Windows 预编译**，请从 `raspberrypi/pico-sdk-tools` 的 `v2.1.1-3` release 取 `picotool-2.1.1-x64-win.zip` 与 `pico-sdk-tools-2.1.1-x64-win.zip`（很小，且自带 CMake config）。
9. 若环境确实没有 picotool，可加 `-DPICO_SKIP_EXTRA_OUTPUTS=1` 跳过，再用 `tools/elf2uf2.py` 把 `.elf` 手动转 `.uf2`。
10. 工具链统一装在 `%USERPROFILE%\.pico-sdk\`，用 `tools/install_deps.ps1` 重建；**这些大包不要提交到 git**（已在 `.gitignore` 忽略）。

## 构建

11. 构建是**可复现**的：全新目录重建后 `.uf2` 的 SHA256 不变，可用于校验源码与固件对应关系。
12. 清理构建目录时，删除文件数较多可能触发批量删除保护；改用**新建构建目录**（如 `build2`）更稳妥。
13. 长构建命令在前台可能被中断；建议后台执行并查看日志。

## 软件 / 功能

14. **软件音量实际未生效**：`rec_take()` 中增益计算被注释，目前只有「静音」真正生效，需要增益要自行实现后写入 24-bit。
15. **WS2812 状态灯占 GP16**；若后续把 GP16/GP17 用作 OLED 的 I²C0，需移除 `src/led.*` 与 `ws2812.pio` 相关代码及 CMake 中的引用。
16. 调试串口占用 **GP0(TX)/GP1(RX)**，115200；`pico_enable_stdio_uart` 开启。

## 烧录 / 使用

17. Pico 的 USB 口**身兼两职**：按住 BOOTSEL 插 = `RPI-RP2` 烧录盘；直接插 = USB 麦克风。不要指望同一时刻既在烧录盘又输出音频。
18. **Windows 会缓存设备名**：改了设备描述符后可能仍显示旧名，需在设备管理器卸载该设备后重新拔插。
19. 主线为立体声透传；**接单颗麦克风时通常只有一个声道有声**（另一声道浮空读无效值），这是预期现象，不是故障。
