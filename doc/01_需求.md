# 01 · 需求

## 目标

做一个基于 **RP2040 Pico** 的 **USB 麦克风**：通过 I²S 采集 MEMS 麦克风音频，经 USB 以 **UAC2（USB Audio Class 2.0）** 送给电脑/主机，被识别为标准免驱音频输入设备。

## 硬件需求

| 项 | 要求 |
|---|---|
| MCU | Raspberry Pi Pico（RP2040） |
| 麦克风 | INMP441（I²S 数字输出，24-bit，MSB-first，标准 I²S 格式，从机） |
| 供电 | **仅 3.3V**（INMP441 不支持 5V），由 Pico 的 3V3（Pin 36）提供 |
| 连接 | I²S 三线：SCK(BCK)、WS(LRCLK)、SD(数据) + VDD/GND + L/R 声道选择 |

## 功能需求

1. **音频采集**：I²S 从机采集，48 kHz，24-bit。
2. **USB 音频输出**：枚举为 UAC2 麦克风设备，主机免驱识别；设备名可配置（当前 `vibecoding-mate mic`）。
3. **声道**：初始设计双麦克风立体声；实际硬件为**单颗 INMP441** 时，需单声道处理（见下）。
4. **状态指示**：原工程用 WS2812（GP16）指示枚举/静音状态（可选）。

## 声道需求（关键约束）

- INMP441 通过 **L/R 引脚接地**选择左声道。单颗麦克风时 I²S 只有左声道槽有有效数据，右声道槽浮空为无效值。
- 因此单麦方案需要：取左声道数据，并（若保持 2 声道描述符）复制到 L 与 R，使输出为「L==R 的伪立体声」；或改为真 1 声道描述符。

## 引脚需求

- I²S 的三个信号必须是**连续 GPIO**，且顺序固定 **SD(最小) → SCK → WS**（受 PIO 程序约束，见 04_注意事项）。
- 主线（v0.3）使用 GP7/GP8/GP9（实际硬件接线，单颗 INMP441 左声道模式），立体声透明透传；早期 v0.2 曾用 GP18/19/20，已回退并舍弃备用板型。

## 非功能需求

- 构建工具链基于 **Pico SDK 2.1.1**，构建结果应**可复现**（同一源码产出同一哈希固件）。
- 固件需按版本号归档，可回溯。
