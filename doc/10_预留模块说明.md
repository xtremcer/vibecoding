# 预留模块说明：状态灯 / OLED / 蜂鸣器（v1.4）

分支 `mic_ptt_led_key-m_BEEP-LED`。把三类外设各做成**独立模块**，只预留接口，方便后续实现。

---

## 1. 额外状态灯 —— `src/status_led.c` / `status_led.h`

| 灯 | 引脚 | 说明 |
|---|---|---|
| busy | GP26（ADC0） | |
| plan | GP27（ADC1） | |
| idle | GP28（ADC2） | |

- 普通 GPIO 输出直驱；点亮电平由 `STATUS_LED_ACTIVE_HIGH` 决定（默认高电平点亮）。
- 接口：`status_led_init()` / `status_led_set(LED_BUSY|LED_PLAN|LED_IDLE, on)` / `status_led_all(on)`。
- 上电默认：`idle` 亮；示例中 PTT(GP2) 按下 → `busy` 亮（见 `main.c`，逻辑可按需改）。

## 2. OLED（I2C1）—— `src/oled.c` / `oled.h`

- 引脚：**SDA=GP10、SCL=GP11**，I2C1，400 kHz，默认地址 `0x3C`。
- 接口：`oled_init()` / `oled_present()`（探测 ACK）/ `oled_write_cmd()` / `oled_write_data()` / `oled_task()`。
- 目前只做**总线初始化 + 底层读写**；显示驱动（SSD1306/SH1106 初始化序列、字库、绘图）后续按需补充。

## 3. 蜂鸣器 —— `src/beep.c` / `beep.h`

- 引脚：**GP14**，需三极管/MOS 驱动（GPIO 直驱电流不够）。
- 适合**有源蜂鸣器**（给电平就响）。
- 接口：`beep_init()` / `beep_on()` / `beep_off()` / `beep_ms(ms)`（非阻塞）/ `beep_task()`（主循环调用）。
- 若用无源蜂鸣器需 PWM 方波，后续可扩展。

## 引脚占用（更新）

| 用途 | 引脚 |
|---|---|
| 按键（buttons.c） | GP0、GP1、GP2、GP3、GP4、GP5、GP12、GP13、GP20 |
| I²S | GP6(dout)、GP7(SD)、GP8(BCK)、GP9(LRCLK) |
| WS2812 / 板载 LED | GP16 / GP25 |
| **新增** | 状态灯 GP26/27/28、OLED GP10/11、蜂鸣器 GP14 |
| **仍空闲** | GP15、GP17、GP18、GP19、GP21、GP22 |

> 不可用：GP23(SMPS)、GP24(VBUS)、GP29(VSYS)。

对应固件：`firmware/i2s_mic_mic_hid_v1.4.uf2`（版本 1.4）。
