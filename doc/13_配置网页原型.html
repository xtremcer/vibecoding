LED 设置

每态：待机灯光（亮/灭 = 无闪烁时的稳态）+ 状态闪烁（点亮ms / 熄灭ms，全 0 = 按待机灯光常亮）。

声音设置

BUSY / IDLE / AUTH 三态各自独立配置；某态的「提示音效」关掉即静音（无全局总开关）。

按键设置

每键 = 按键1(修饰: 无/Win/Ctrl/Alt/Shift) + 按键2(具体键) + 触发行为 + 单击时长(ms)。
· 按键1=无 → 只映射一个按键(按键2)；按键1≠无 → 两个按钮组合(修饰+主键)同时按下释放。
· 按键2 列表里没有"无"选项（必有具体键），所以要禁用某个宏，请用该卡的「启用」勾选框。
· 正常：按下宏=按下对应键，松开宏=松开对应键（跟随物理按住）。
· 单击：不管物理按多久、保持多久，都只触发一次组合键的按下+弹起；单击时长控制这一次按下的保持时长。
